# Raccoon Rampage ⪩. .⪨

A strategic puzzle game where you trap raccoons by pushing recycling bins and locking garbage cans before they escape.

## Gameplay

Raccoons are trying to climb into garbage cans. Your job is to trap them using recycling bins before they get there.

- **Regular raccoons** move randomly
- **Smart raccoons** (with glasses) actively hunt for open garbage cans
- **Recycling bins** chain-push when you shove them into each other
- **Garbage cans** can be locked by walking into them

A raccoon is trapped when it's surrounded on all four sides by bins, other raccoons, you, or the board edge.

**Scoring:** 10 points per trapped raccoon + bonus for clustering your recycling bins together.

## Controls

Arrow keys to move. That's it.

## Run it
```bash
pip install pygame
python3 main.py
```
